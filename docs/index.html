Try to touch Gojo. Move to attack. Click or tap to throw blasts. Keyboard: arrows to move, space to throw.

GAP - HALVINGS - ZOOM - TOUCH NEVER

Inside Infinity your speed is proportional to the gap left: ġ = −k·g, so g(t) = g₀·e^(−kt) > 0 for every t. Each halving takes the same time ln2/k, so touching needs infinitely many halvings and infinite time.

The gap is stored as ln(g), not g. A plain float would underflow to exactly 0 after a few minutes and fake a touch.
